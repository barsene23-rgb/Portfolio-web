2MG Sports Park

Founder & solo developer · 2025–present

My own sports gear business — Nike, Adidas, Jordan, New Balance, Puma, and NBA-licensed gear, sold from two branches in Kigali. I built the site and everything behind it myself. It started as a single HTML file with hardcoded product images and a fake payment button that just ran a timer.

It's grown into a Node/Express backend with an admin dashboard, a membership system issuing member IDs (2MG-XXXX-XXXX), and order tracking with spend analytics. The storefront pulls category filters live from a /categories endpoint instead of hardcoding them.

Moving onto Render meant leaving local SQLite behind — the database now lives on Turso (libSQL) and images go through Cloudinary. The frontend deploys on Netlify, connected to a custom domain.

A bug worth mentioning The admin dashboard went blank after every Render restart because Render was silently regenerating the auth token. Fixed by pinning ADMIN_TOKEN as a fixed env variable and adding 401 detection that clears stale tokens automatically.

Checkout runs through WhatsApp with a shareable order-summary page. On payments, I tried PayPack Rwanda, then MTN MoMo, then Pesapal in parallel, before settling on MTN MoMo as the live default, with Airtel Money and WhatsApp as fallbacks.

CHUK DDS

Developer · hospital department management system

DDS (prototyped first as "careMe") is a department management system for CHUK hospital, running over the hospital's own LAN. It's Node/Express and MySQL, expected to handle 500–700 concurrent users — a scale that changes how carefully you have to build.

Early work was infrastructure: MySQL setup, a missing script in package.json, a bcrypt dependency issue, and ES module conversion. The data layer now runs on better-sqlite3 in WAL mode, wrapped in a db.js module that mimics the old mysql2 pool interface.

Bugs that mattered A department name-to-ID bug in POST /api/users was mis-assigning staff. The login route also wrongly required a role field, locking out valid users. Both fixed and verified against a real admin account.

Now setting up a staging workflow with GitHub branching, so changes get tested before touching the live deployment.

  • LAN-only deployment
  • WAL-mode storage layer

Ukurikira League Ops

Program Manager & Head of Referee · TCL, 2025–present

Not all my work is code in a browser. TCL runs Ukurikira, a weekly basketball program across multiple courts, and I manage both the schedule and the referee crew.

After a Season 2 scoring error (incident REC-12) traced to an undertrained table crew, I wrote a Table Crew Protocol & Training Manual. A separate fix for chronic late starts: a Game Night Start Time SOP with a T-30/T-20/T-15/T-0 countdown and a forfeit rule for Season 3.

Both documents were generated with the docx Node library rather than formatted by hand — same instinct as any other structured output: define the sections once, generate consistent formatting every time.
